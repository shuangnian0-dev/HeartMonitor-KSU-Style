# 心率监测 · KSU 风格完整工程

基于最新的 Java Android 源码工程整合，原有 BLE 直连、断线重连、实时心率、心率历史、趋势曲线、ECG 风格动态曲线、设备信息、主题设置、液态玻璃、悬浮窗、心率范围配置和数据清理功能均保留。


## 本次界面重铸

- 视觉方向收敛为 KSU 式中性界面：减少装饰贴图和大面积强调色，保留清晰状态、分组卡片与底部胶囊导航。
- 全局标题改为更紧凑的字号与 `sans-serif` 字体层级，次级信息降低对比度，按钮与列表间距统一。
- 液态玻璃按你提供的配方调整为薄色纱、上下双色边缘和轻微材质层次；底部导航不再逐帧截图或模糊页面，滚动内容由 Android 正常实时合成。
- 主题设置保留明暗模式、动态取色、自定义主题色、背景图、读取桌面壁纸、玻璃色调/透光程度/材质层次/边缘反光/圆角、页面缩放、启动动画和触觉反馈。
- 首页不再依赖角色贴图或大图标建立视觉焦点；桌面小组件恢复角色图，图片已从现有应用图标分离为透明 PNG，可直接替换。
- 新增 `界面自定义说明.md`，列出页面构建、全局样式、玻璃材质和功能代码位置。

## 已整合功能

- **BLE 连接与诊断**：标准 BLE 心率 `180D/2A37`，兼容已有的小米旧款 `FEE0/FEE1/FFxx` 与部分 `3512` 特征；保留 GATT 串行操作、原始数据包记录、服务列表及断线退避重连。
- **设备管理**：自动记住已连接设备，可在“设备管理 → 已保存设备 / 多设备管理”中切换或移除设备记录；设备信息页会显示心率通道兼容情况、电量读取状态、RSSI、步数、厂商、型号、固件和数据包计数。
- **一键诊断报告**：可生成带系统/App 版本、连接状态、信号、电量、心率、GATT 服务及原始数据摘要的文本报告。蓝牙地址会默认遮挡部分字符，避免无意泄露完整地址。
- **历史数据中心**：统计区间支持今日、近 7 天、近 30 天；图表按选定区间刷新，保留最近记录列表。
- **CSV 备份与恢复**：导出时通过系统文件选择器保存 UTF-8 CSV；可以再次选择 CSV 导入并合并记录，导入会校验心率和时间，并跳过数据库中已有的相同心率/时间记录。
- **后台监测与 BLE 交接**：监测或悬浮窗开启时启动前台服务。应用处于前台时沿用原有 GATT 逻辑；应用进入后台后释放 Activity 的 GATT，由后台服务连接已保存设备、订阅标准 180D/2A37 心率通知并自动重连。真实心率持续写入数据库、组件趋势和悬浮窗。Android 强制停止、权限未授予、蓝牙关闭或设备只提供未实现的厂商私有协议时，仍不能保证连接。
- **心率范围提醒**：可设置低/高阈值，并独立开启超限系统通知；提醒最多每分钟发送一次，避免设备连续推送时通知刷屏。Android 13 及以上需要允许通知权限。
- **低功耗模式**：默认使用均衡蓝牙连接优先级，并把电量读取间隔调整到 60 秒；关闭后切换为响应优先并缩短电量轮询间隔。心率仍由 BLE 通知按设备实际数据更新。
- **主题与交互**：保留 KSU 风格主题页、动态取色、自定义背景、桌面壁纸图片、全局液态玻璃、切页手势、底栏调整、触摸/触觉反馈和悬浮窗自定义。

## 设备兼容说明

标准 BLE 心率设备可通过 `180D/2A37` 通道直接传输心率。部分新款小米设备可能使用认证、加密或厂商私有协议，仅靠通用 BLE UUID 无法保证读取实时心率、睡眠等全部数据。连接后若没有新数据包，请在设备页打开服务列表或分享诊断报告，以便进一步识别具体协议。

## 构建

使用 Android Studio 或 CodeAssist 打开项目根目录，安装 Android SDK Platform 36，并使用 JDK 17 或更新版本。工程使用 Gradle 8.13 与 Android Gradle Plugin。

本次环境没有可用的 Android SDK，Gradle 8.13 下载也因 `services.gradle.org` DNS 不可达而失败，因此无法在当前环境真实构建 APK。项目包包含完整源码、Gradle Wrapper 与工程配置；请在能正常下载 Gradle/Android SDK 的 Android Studio 或 CodeAssist 中执行构建。当前已检查工程内 XML，并对主要 Java 文件进行了括号、字符串和注释边界校验；这不等同于 Android 完整编译或真机蓝牙验证。

## 桌面快捷小组件

本版本提供一个深色实底的心率快捷控制小组件（不使用液态玻璃）。角色图片位于 `app/src/main/res/drawable-nodpi/widget_mascot.png`，使用透明背景并恢复到原布局位置；主界面不再显示角色贴图，避免装饰抢占数据层级。数据导出、导入和清空入口归入隐藏的开发者功能，默认不显示。小组件顶部为椭圆形“一键开启/一键关闭”按钮；状态区域分别显示监测开关、悬浮窗开关和设备连接状态；心率区域展示最近一次真实心率，并用仅由真实 BLE 样本更新的迷你趋势线展示最近变化。趋势数据和最后更新时间保存在应用的 `app_preferences` 中，应用收到新心率时会同步刷新小组件和已打开的悬浮窗。

添加方法：长按桌面空白处，打开系统“小组件”，找到“心率快捷控制”并放到桌面。组件点击不会主动打开主界面。它会启动/停止前台监测服务，并在悬浮窗权限已授予时启动/停止悬浮窗。请先在应用内授予蓝牙权限并成功连接、保存设备；后台服务优先按已保存地址自动连接并订阅标准 BLE 心率服务。若设备需要尚未实现的厂商私有认证/测量协议，服务会显示连接状态但可能收不到心率数据。Android 强制停止应用或用户撤销权限也会阻止后台自动连接。

### 液态玻璃独立控制
- `主题液态玻璃` 控制应用页面、卡片和图表等主题表面。
- `底部切换栏液态玻璃` 独立控制下方页面切换栏，不依赖主题玻璃开关。
- `透光程度`、`材质层次`、`边缘反光`、`圆角幅度`均可单独调整。
- 底部栏不再采样页面截图或执行逐帧模糊；滚动内容由 Android 正常绘制并实时透出。浅色模式采用瓷白半透材质和深色标签，深色模式采用石墨色材质。

## 液态玻璃重构说明

本版按 `liquid-glass-recipes` 的液态玻璃方向调整为薄色纱、上下双色边缘、顶部细反光和轻微材质层次。原生 Android View 不直接支持 CSS 的 `backdrop-filter: url(#lens)`，因此不伪装成截图折射：玻璃层保持轻量透明，由系统合成当前页面内容，避免旧截图、模糊任务与滚动卡顿。普通内容卡片使用轻透表面，底部栏则使用更高对比度的主题专属材质。

### 使用桌面壁纸照片 / 视频
在「主题设置 → 背景」打开「使用桌面壁纸」：
- Android 12L 及以下：申请 `READ_EXTERNAL_STORAGE`，然后尝试读取当前静态壁纸快照。
- Android 13：在功能开启时申请 `READ_MEDIA_IMAGES` 和 `READ_MEDIA_VIDEO`，再由系统文件选择器选择当前桌面壁纸的原始照片或视频。
- Android 14 及以上：同时声明并请求 `READ_MEDIA_VISUAL_USER_SELECTED`，兼容用户只允许部分照片/视频的访问方式。
- 照片作为静态背景；视频以静音循环方式播放，应用进入后台时自动暂停，返回前台继续。
- Android 13 起，照片/视频权限并不等于系统壁纸读取权限。系统不允许普通应用通过 `WallpaperManager.getDrawable()` / `getWallpaperFile()` 读取真实壁纸源文件；因此新系统需要用户选取壁纸原图。应用不会申请 `MANAGE_EXTERNAL_STORAGE` 所有文件访问权限。
- 关闭壁纸背景后恢复之前导入的自定义背景或默认背景。壁纸媒体 URI 与自定义背景分别保存，不会互相覆盖。

### 底部导航选中态
选中项改为低透明度主题色胶囊，图标与文字提高对比度；整条玻璃底栏降低不透明度，让壁纸更明显地透出。浅色模式和深色模式分别计算选中背景、文字和描边颜色。

## 自动读取当前桌面壁纸（本次更新）

“使用桌面壁纸”现在改为直接读取系统当前桌面壁纸，不再自动打开照片/视频选择器。

- Android 12L 及以下：使用 `READ_EXTERNAL_STORAGE` 读取系统壁纸。
- Android 13 及以上：系统的 `WallpaperManager.getDrawable()` 对普通应用限制了真实壁纸读取。本工程增加可选的 `MANAGE_EXTERNAL_STORAGE` 特殊访问流程。用户开启壁纸功能后会先看到说明，再自行进入系统设置允许“所有文件访问”。不会在应用启动时自动申请。
- 授权后读取 `WallpaperManager.getDrawable()` 并在应用私有目录缓存，避免每次进入页面重复解码。
- 每次应用回到前台时比较 `WallpaperManager.getWallpaperId(FLAG_SYSTEM)`；发现系统壁纸 ID 变化后自动重新读取。
- 不再为这一功能申请 `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`，普通自定义图片/视频仍可通过系统文件选择器单文件授权。

**隐私与发布提醒：** `MANAGE_EXTERNAL_STORAGE` 是范围很大的“所有文件访问”权限，用户必须在系统设置中单独授权。Google Play 对此权限有严格用途限制；本应用并非文件管理器，若计划通过 Google Play 发布，不应默认依赖该权限，应改用单文件系统选择器方案。此功能适用于用户明确知情并自行授权的侧载版本。

动态壁纸是否能提供可读取的静态图像取决于设备厂商与壁纸服务实现；此实现直接读取系统暴露的壁纸 Drawable，不承诺录制动态壁纸实时帧。
